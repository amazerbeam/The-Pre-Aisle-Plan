CHARACTER HEIGHT SCALE (v2 — updated for the stadium-riser full-canvas layout)
Anchor: Arthur Morgan (Red Dead Redemption 2) = 185cm real -> 6cm on poster
  (was 12cm in v1 — halved to fit far more characters via the riser-row
  technique, growing the poster edge to edge instead of one corner)
Scale factor: 6 / 185 = 0.0324 cm-poster per cm-real  (~1:30.8)
Print target: 45 x 30cm @ 300dpi (5315 x 3543 px)

LAYOUT: stadium-riser crowd, not a single corner huddle. Front row stands at
canvas-bottom, full height. Each row behind rises up the canvas so it's never
covered past its own chest by the row in front — using the anthropometric
rule that chest height sits ~72% up a standing body, each row must rise by
at least height x (1 - 0.72) = height x 0.28 above the row in front.
At the 6cm anchor height this is a ~1.68cm rise per row.
  6cm (row 1) + (rows-1) x 1.68cm <= 30cm  ->  15 rows fit total.
Per-row width: a standing silhouette (with prop/arm spread) runs roughly
0.35x its height -> ~2.1cm wide at 6cm tall. Packed shoulder-to-shoulder
with natural crowd overlap: ~21-25 characters per row across 45cm.
THEORETICAL CAPACITY: 15 rows x ~21-25/row =~ 315-375 characters.
GOAL (per owner, 2026-08-21): fill the grey space — aim big, not a small
curated cap. Roster building is actively expanding toward this capacity.

RULE (unchanged): "Largest HUMAN character = 6cm" is satisfied by Arthur as
the tallest ORDINARY human. Non-human (Mewtwo), demigod (Kratos), or
powered-armor (Master Chief) characters may exceed 6cm on their own
real/lore height.

"official" = stated in-game/dev/wiki-documented canon figure
"estimate" = no official source found; reasoned from model proportions / genre convention
