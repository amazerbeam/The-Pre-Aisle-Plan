Header & logo: make the brand visible and the bar useful

The logo is drawn with thin strokes at 32px inside a translucent circle, so on screen it shows as a smudge. It's the only branding in the app: the tab title says "Recipe Viewer", the sign-in screen has no mark, and phones get no home-screen icon. Meanwhile the bar's middle is a raw date box. These ideas give the app a name you can see and a header that helps you get around.

The ideas

Spec panel (please red-line)

  • Chosen logo: C · Plate P (2026-11-14): a purple #4a3f80 rounded tile, a white plate, a purple "P" as the meal, and a Pip-green leaf.
  • One logo source: a BrandMark React component (an inline SVG with a size prop, solid white tile + brand glyph) used in the header, sign-in modal and landing. Static exports (favicon.svg, apple-touch-icon.png 180, icon-192.png, icon-512.png, icon-maskable-512.png) are generated from the same SVG.
  • Sizes: 40px web header, 36px mobile header, 72px sign-in, 120px landing, 16/32 favicon, 180 Apple, 192/512 PWA. The mark never sits inside a translucent circle again; it is the tile.
  • Colours: the brand purple #4a3f80 (replacing the favicon's #6B46C1), white tile, Pip green #7cc36b only for the sprout/leaf accent (B, C).
  • Wordmark: "My Pantry Plan", system font, 800/500 weights. It shows on desktop and on phones ≥360px wide; below that, the mark only.
  • Header height: 64px on web, 98px on mobile (two rows). The header stays the z-index 100 stacking context (see the comment in Header.css).
  • Desktop nav in the header from 1024px up. The bottom Footer nav hides at that width; below it, nothing changes.
  • The week control is the one from the Meal Plan redesign (Task 12), just restyled here as a pill. It's the same component, not a second one.
  • Tab title: "My Pantry Plan", plus the section name per route ("Meal Plan · My Pantry Plan").
  • The account menu keeps every control it has today (DefaultPortionsControl, MealTimesControl, Sign out, VersionInfo); only the grouping and order change.
