Pip robot: faces on the screen

Cyberpunk only. The robot's three face items (glasses slot) are redrawn as pixels the CRT screen is displaying, on the screen's pixel grid, clipped to the glass and under the scanlines. While one is worn it replaces the base face; take it off (or let Pip fall asleep) and the base face comes back. Today Smiley.exe is a smooth yellow disc floating on the monitor, which reads as a sticker, and Shades.gif sits on top of the base eyes. Each item has two options; pick one per row. Item ids, slots and unlocks don't change.

The swap

Wearing an item doesn't stick anything on: the screen changes channel (it collapses to a bright line and opens on the new face). Taking it off plays the same flicker back to the base face. It stops under Low FX and reduced motion, so the face just swaps.

How it would build

  • Every robot face item is a pixel bitmap (rows of characters plus a palette) instead of free shapes. It is drawn centred on the form's screen (ROBOT_SCREEN), with a pixel size chosen so it fits that screen, so it lands on the screen's grid on all three forms.
  • Clipped to the glass. A clip path of the screen's inner rect keeps the face on the screen (that's also what lets the shades scroll in from the top edge). The scanlines are drawn again on top so the face looks displayed, not printed.
  • REPLACES_FACE covers all three (round-specs, heart-glasses, sunglasses). Shades.gif stops layering over the base eyes. Asleep shows the base sleep face; bored dims the item's face like the base face.
  • Rule for later robot face items: any new item that changes the face is a screen bitmap that replaces the base face, never a shape on top.
  • New effects (looped shades drop, glint, CRT channel change) go in Pip.css and stop under Low FX and reduced motion like the others.
